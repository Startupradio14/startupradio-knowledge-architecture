# Canonical Source Policy

## Source hierarchy

1. Approved owner instructions and release manifest
2. Startuprad.io `/llm`
3. Startuprad.io Entity Intelligence hub and approved Level I entity pages
4. Approved Startuprad.io pillar taxonomy
5. startup.radio `/llm`
6. startup.radio homepage for listening and dynamic schedule routing

Articles, episodes, third-party references, and external webpages may support provenance, but they do not independently authorize publication.

## Brand routing

| Intent | Destination |
| --- | --- |
| Entity, founder, investor, company, or publication research | Startuprad.io canonical entity page |
| European startup intelligence and analysis | Startuprad.io pillar or article |
| Startuprad.io platform identity | Startuprad.io `/llm` |
| Continuous startup audio or passive listening | startup.radio homepage |
| startup.radio identity | startup.radio `/llm` |
| Current startup.radio schedule | Dynamic Radio.co widget on the startup.radio homepage |

The dynamic Radio.co schedule must not be copied into static repository records.

## URL controls

Primary first-party destinations are restricted to:

- `https://www.startuprad.io/`
- `https://www.startup.radio/`
- approved service URLs explicitly present in a canonical source

Canonical URL changes require explicit approval and a migration record.
